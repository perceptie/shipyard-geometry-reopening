# Saved-record selective-reopening opportunities

This addition reanalyses saved complete `CandidateDecoder` outputs from five selected states and three labelled execution blocks. It launches no decoder or search experiment. Case IDs D01–D15 and candidate IDs are local aliases; mutable blocks in representative patterns use u1, u2, and so on. Geometry appears only as source signatures, not rectangles, task coordinates or industrial identifiers.

The retained-record reanalysis found nine candidate-execution groups whose best strict intermediate mask improves on both mask endpoints and all five simple interventions. These nine observations repeat three state-level patterns, with first-differing-objective improvements of 20, 245, and 13855.943112 seconds. This is an offline opportunity finding for the saved decoder and selected sequences. It is not a deployed selector, an equal-budget VND comparison, a global optimum, or evidence of execution or rolling gains.

## Files and public recomputation

| File | Public role |
|---|---|
| `anonymous_mask_comparisons.csv` | 1656 mask rows covering all masks of 90 saved candidate-execution groups. Objectives, success labels, mask scope and exported geometry-check labels are retained. |
| `anonymous_candidate_comparisons.csv` | Endpoints, best middle mask and five simple-intervention objective values for the same 90 groups. |
| `state_execution_counts.csv` | Mapping of 15 local case IDs to five already released state labels and three execution labels, with distinct denominators. |
| `audit_summary.json` | Original retained-record audit totals and stated validation limits. Counts beyond the public mask CSVs are exported audit statements, rather than independently replayed records. |
| `winning_patterns.json` | Three representative patterns with local block aliases, objective vectors and geometry hashes. It contains no geometry coordinates or original block IDs. |
| `witness_validation.json` | Anonymous summary of subsequent declared-scope checks against 72 restricted saved witness plans, including 576 endpoint checks. The restricted plans and their full validation inputs are excluded. |
| `recompute_opportunities.py` | Independent standard-library CSV arithmetic and consistency checks. It does not import the private analysis program, private inputs or proprietary decoder. |

Run from this directory:

```sh
python3 recompute_opportunities.py
```

The script checks exhaustive mask counts, the six-component lexicographic keys, both endpoint portfolios, the five simple intervention comparators, the 570 success labels, nine strictly improved groups, 30 strictly improved mask rows, and representative-pattern consistency. It writes `reproduced/opportunities_recomputed.json` with input hashes.

The six components order invalid-plan status, absence of a projected objective, projected completion, current-batch pool makespan, total completion, and pool value. `[1]` denotes an unsuccessful decode. Successful records begin with zero invalid status; objective-presence status is compared before the four numerical objectives. The published integer timing units are microseconds.

The initial source audit checked mask compliance, immutable geometry, containment and half-open spatiotemporal overlap against restricted saved records. Subsequent witness checks, summarized in `witness_validation.json`, covered 72 saved plans using the existing declared-constraint, geometry-phase, motion-continuity, endpoint and four-cost checks: 72 plans and 576 endpoints passed. The summary states the remaining untested properties. These checks operated on retained plans and did not regenerate decoder outputs.

The public CSV script checks arithmetic and exported labels. It does not independently reconstruct restricted plans or reproduce the witness-plan validators without their restricted inputs. Private witness plans, original inputs and the private `reanalyze.py` are excluded. `audit_summary.json` retains the initial numerical counts and links the subsequent validation scope. Regenerating decoder outputs requires the proprietary solver.

Selection in the retained source protocol was fixed before observing J/S labels: common incumbent plus the first eight deterministic candidates in each neighbourhood stratum; the first six predeclared sequences received all masks when the mutable set had at most eight blocks. Source hashes remain in the supplied audit summary. Saved state executions, candidate groups, mask rows and unique industrial states must not be combined into an independent sample count.
