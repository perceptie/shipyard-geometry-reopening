# Public reproduction package

- Runtime: Python 3.12; plotting uses Matplotlib 3.11.2 and NumPy 2.5.3. The two plan-checking scripts use the standard library.
- Run the three reproduction/checking commands in the root README from `Online_Resource_1/`. Generated outputs belong in its ignored `reproduced/` directory.
- Preserve released numerical records and their provenance. Refresh `SHA256SUMS` when an authorized release-file edit changes a file's content.
- Release boundary: de-identified aggregates, case-local records, reproduction code, and synthetic examples only. Keep private industrial solver code, customer source data, credentials, and restricted execution records outside this repository.
